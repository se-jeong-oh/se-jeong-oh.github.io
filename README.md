# 동행 — 오세정의 여행 기록

https://se-jeong-oh.github.io/

함께 떠났던 사람들과 그곳에 대한 기록입니다. "여행을 많이 다녔다"가 아니라 **다양한 사람들과, 다양한 곳을 다녔다**는 이야기를 합니다.

## 컨셉: 창가 자리

- **나는 늘 창가 A석에 고정**되어 있습니다(검은 좌석 "나").
- 여행이 바뀔 때마다 바뀌는 건 **창밖 풍경(사진)** 과 **옆자리의 사람(좌석)** 뿐입니다.
- 본문은 잡지 기사처럼, 오른쪽 여백은 책 맨 뒤의 **색인**처럼 만들었습니다. 사람으로도 장소로도 여행을 찾을 수 있습니다.
- 스크롤하면 화면 가운데를 지나는 장(여행)에 맞춰 창밖 사진이 기차 창밖처럼 옆으로 흘러가고, 좌석이 옆자리부터 채워집니다.

## 이야기와 사진 넣기

### 1. 사진 파일 넣기

1. `photos/` 아래에 여행 번호로 폴더를 만듭니다. 폴더 이름은 `photos/README.md`의 표를 따릅니다(예: `photos/07-sapporo/`).
2. 사진을 `01.jpg`, `02.jpg` … 이름으로 넣습니다. 영문·숫자만, 공백 없이.
3. **첫 번째 사진이 큰 창문(창밖)** 에 들어갑니다.
   - 세로로 긴 둥근 창이라 가운데가 잘려 보입니다.
   - 세로 사진이나, 주제가 가운데에 있는 사진이 잘 맞습니다.
   - 나머지 사진은 본문 아래에 두 장씩(4:3으로 잘림) 놓입니다.
4. 크기는 긴 변 2000px, 한 장 500KB 이하를 권장합니다. 맥에서는 이렇게 줄일 수 있습니다.
   ```sh
   # 긴 변 2000px, JPEG 품질 80 (원본을 덮어씀. 원본은 따로 보관하세요)
   sips -Z 2000 -s formatOptions 80 photos/07-sapporo/*.jpg
   # 아이폰 HEIC → JPG
   sips -s format jpeg IMG_0001.HEIC --out photos/07-sapporo/01.jpg
   ```
5. 공개 사이트입니다.
   - 다른 사람 얼굴이 크게 나온 사진은 당사자에게 먼저 물어보세요.
   - 사진에 촬영 위치(GPS)가 들어 있을 수 있습니다. 사진 앱에서 내보낼 때 위치 정보를 끄거나, `exiftool -gps:all= -overwrite_original photos/*/*.jpg` 로 지우세요.

### 2. `content.js`에 적기

`window.TRIPS`의 여행 하나가 이렇게 생겼습니다. **배열 순서가 곧 01, 02 … 번호**입니다.

```js
{
  places: ['삿포로'], who: 'parents', when: '2019년 2월', stage: '', tone: 'sapporo',
  story: [
    '첫 번째 문단.',
    '두 번째 문단. 문단 하나가 배열의 한 칸입니다.',
  ],
  photos: [
    { src: 'photos/07-sapporo/01.jpg', alt: '눈 덮인 오도리 공원', caption: '오도리 공원, 눈 오던 밤' },
    { src: 'photos/07-sapporo/02.jpg', alt: '시계탑 앞의 부모님', caption: '시계탑 앞에서', focus: '50% 30%' },
  ],
},
```

| 항목 | 뜻 | 비워 두면 |
|---|---|---|
| `places` | 장소 이름. 한 번에 여러 곳이면 여러 개 (`['호주', '뉴질랜드']`) | 필수 |
| `who` | 함께 간 사람. `window.PEOPLE`의 키 (`parents`, `friends`, `grad`, `disciples`, `village`, `wife`) | 필수 |
| `when` | 연도나 시기 (`'2019년 2월'`) | 표시 안 함 |
| `stage` | 삶의 시기 (`'대학생'`, `'신혼여행'`) | 표시 안 함 |
| `tone` | 사진이 없을 때 창밖에 보여줄 색 (`style.css`의 `.tone-*`) | 하늘색 |
| `story` | 이야기 문단들 | "이 여행의 이야기를 준비하고 있습니다." |
| `photos[].src` | 사진 경로 | 창밖에 `tone` 색과 "사진 준비 중" |
| `photos[].alt` | 사진 설명 (화면 낭독기용). 무엇이 찍혔는지 짧게 | 장소 이름 |
| `photos[].caption` | 사진 아래 캡션. 첫 사진의 캡션은 창문 아래 `fig. 07` 옆에 나옴 | 첫 사진은 "창밖, 장소", 나머지는 없음 |
| `photos[].focus` | 잘릴 때 기준점 (`'50% 30%'` = 가로 가운데, 세로 위쪽 30%) | 가운데 |

- 글 안의 `<`, `>` 같은 기호는 그대로 글자로 보입니다(HTML로 해석하지 않음).
- 작은따옴표(`'`)가 글에 들어가면 `\'`로 쓰거나, 그 문단을 큰따옴표(`"…"`)로 감싸세요.
- 사진 파일 경로가 틀리면 창밖은 색으로 바뀌고, 본문 사진은 빠집니다.

### 3. 사람과 인원

`window.PEOPLE`에서 고칩니다.

```js
parents: { name: '부모님', with: '부모님과', total: 3, color: '#cc6a33' },
```

- `total`은 **나를 포함한 인원**입니다. 좌석이 2열 8석이라 최대 8명입니다.
- 좌석은 옆자리 → 뒷줄 → 통로 건너 순서로 채워집니다.
- `color`는 좌석과 점에만 씁니다. 글자색으로는 쓰지 않습니다(배경과의 대비가 부족함).

### 4. 사이트 문구

`window.SITE`에서 고칩니다.

| 항목 | 내용 |
|---|---|
| `title` | 사이트 이름(지금은 임시로 '동행') |
| `tagline` | 한 줄 소개 |
| `intro` | 자기소개 문단 |
| `concept` | 첫 화면의 창가 자리 설명 |
| `closing.line` / `closing.body` | 마무리 한 줄과 문단 |
| `links` | 아래 링크 |

사이트 이름을 바꾸면 `index.html`의 `<title>`과 `og:title`, `og:description`도 같이 고쳐 주세요. 링크를 공유했을 때 미리보기에 쓰입니다.

## 레이아웃 검사

디자인이나 글을 크게 바꾼 뒤에는 검사를 돌립니다. Node 22 이상과 Chrome이 필요합니다.

```sh
python3 -m http.server 8000 &
node tools/check-layout.mjs http://127.0.0.1:8000/ /tmp/layout-shots
```

- 7가지 화면 크기(1440, 1280, 1180, 1024, 820, 390, 360px)에서 각 장을 화면 단위로 끝까지 내려가며 검사합니다.
- `report`가 비어 있으면 통과입니다.
- 문제가 있으면 `overlap`(글자 겹침), `h-overflow`(가로 넘침), `text-offscreen`, `truncated`(말줄임으로 잘림), `v-overflow`(상자 밖으로 넘침)로 알려줍니다.
- 스크린샷은 `/tmp/layout-shots/<가로>x<세로>/<장 id>.png`에 남습니다.
